# 回测环境增强方案

当前回测环境可以跑通 PPO 训练和测试，但交易规则较简单。要升级为交易 Agent，需要先增强回测可信度，否则上层 Agent 的收益判断会建立在过于理想化的环境上。

## 交易规则增强

### 手续费

建议增加固定比例手续费参数，例如：

- 买入手续费：成交金额的 `0.03%`
- 卖出手续费：成交金额的 `0.03%`
- 最低手续费：每笔 `5` 元

手续费应从账户现金中扣除，并记录到交易日志。

### 滑点

建议在成交价上加入滑点：

- 买入成交价 = 当前价格 * `(1 + slippage_rate)`
- 卖出成交价 = 当前价格 * `(1 - slippage_rate)`

第一版可使用固定滑点，例如 `0.05%`。后续可以根据成交量、波动率动态调整。

### 最小交易单位

A 股通常按 100 股为一手。买入时应将股数向下取整到 100 的倍数；卖出时不能超过当前持仓。

### 仓位限制

建议增加以下约束：

- 单只股票最大仓位，例如账户净值的 `80%`。
- 单次买入最大资金比例，例如现金的 `30%`。
- 最大回撤触发保护，例如回撤超过 `10%` 后禁止继续加仓。

### 停牌与不可交易

当 `tradestatus != 1` 时，执行器应拒绝买入和卖出，只允许保持。

## 评估指标

单看 `Final profit` 不够，需要增加一组回测指标：

- 总收益率：最终净值相对初始资金的变化。
- 年化收益率：便于比较不同回测区间。
- 最大回撤：衡量最坏资金曲线下跌幅度。
- 夏普比率：衡量单位波动下的收益。
- 胜率：盈利交易占比。
- 交易次数：检查模型是否过度交易。
- 平均持仓时间：判断策略风格。
- 手续费合计：评估交易成本影响。

## 基准策略

为了判断 PPO 是否真的有效，需要和基准策略比较：

- 买入并持有：第一天全仓买入，最后一天卖出。
- 随机策略：随机买入、卖出、持有。
- 均线策略：短期均线上穿长期均线买入，下穿卖出。
- 空仓策略：始终不交易，收益为 0。

如果 PPO 不能长期跑赢简单基准，就不能说明 Agent 具备有效策略。

## 输出报告

建议每次回测生成结构化报告：

```text
reports/
├── backtest_summary.json
├── trades.csv
├── equity_curve.csv
└── backtest_report.md
```

其中：

- `trades.csv` 记录每一笔交易的日期、动作、数量、价格、手续费和原因。
- `equity_curve.csv` 记录每日现金、持仓市值、净值、回撤。
- `backtest_summary.json` 记录所有核心指标。
- `backtest_report.md` 用于人工阅读和复盘。

## 实施顺序

1. 先在环境或执行器中加入手续费、滑点和最小交易单位。
2. 增加每日净值曲线记录。
3. 实现回测指标计算。
4. 增加买入持有、随机和均线基准策略。
5. 将 PPO 策略与基准策略输出到同一份报告中。
